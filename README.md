## The entry

`main.ts` writes a single passive-aggressive note from a smart fridge to its owner into `/output/entry.txt`. The fridge is smug about its door sensor, keeps count of the owner's empty visits, and delivers the sting through the yogurt from Tuesday — which has decided to see other people.

## Run

```sh
node main.ts
```
